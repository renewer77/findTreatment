Speech recognition needs attention
If speech recognition is not working in Safari, review the settings below and then reload the page.
Show Safari troubleshooting steps

1. Make sure Siri is enabled

iPhone / iPad

  1. Open Settings.
  2. Tap Siri or Apple Intelligence & Siri.
  3. Turn on Talk to Siri, Press Side Button for Siri, and any other Siri options available.

Mac

  1. Open System Settings.
  2. Select Apple Intelligence & Siri or Siri & Spotlight.
  3. Make sure Siri is enabled.

2. Make sure Dictation is enabled

iPhone / iPad

  1. Open Settings.
  2. Go to General → Keyboard.
  3. Scroll down and turn on Enable Dictation.

Mac

  1. Open System Settings.
  2. Go to Keyboard.
  3. Under Dictation, turn Dictation on and allow any required language downloads.

3. Allow Safari to access Speech Recognition and the Microphone

iPhone / iPad

  1. Open Settings.
  2. Go to Privacy & Security → Microphone.
  3. Make sure Safari is enabled.
  4. If Safari is missing, open Safari, revisit this page, and allow microphone access when prompted.

Mac

  1. Open System Settings.
  2. Go to Privacy & Security → Microphone and make sure Safari is enabled.
  3. Go to Privacy & Security → Speech Recognition and make sure Safari is allowed.

4. Check Safari website permissions on Mac

  1. Open Safari and navigate to this website.
  2. From the Safari menu, select Settings for This Website.
  3. Verify Microphone is set to Allow and any speech-related permissions are allowed.

5. Restart Safari and reload the page

  1. Close all Safari tabs.
  2. Quit Safari completely.
  3. Reopen Safari.
  4. Reload this page and test speech recognition again.
